## DevOps Winter Arc — Day 07 Project

### Project Purpose
This project demonstrates a production-grade Git and GitHub branching workflow combined with an infrastructure reverse proxy simulation.

### Git Workflow Followed
- Initialized local repository and tracked base configurations.
- Isolated code deployment using a dedicated feature branch (`feature/health-check`).
- Managed remote authentication securely using Fine-grained Personal Access Tokens (PAT).
- Opened, reviewed, and merged code changes via GitHub Pull Requests (PR).

### Production Challenge Summary
Simulated and diagnosed an upstream service failure (HTTP 502 Bad Gateway) using Nginx error logs and recovered the infrastructure workflow seamlessly.
